Issues, ordered by player impact

P1 · ISS-01

Android input ANR during checkout-to-leaderboard navigation

Observed: An Android ANR dialog appeared, and ActivityManager recorded a 5,112 ms MotionEvent timeout. Repeated Wait did not provide lasting recovery. Video 06 shows the ANR dialog at 00:50.

Reproduce: Add Credits, no wallet → Tap Connect twice rapidly → Press Android Back → Tap Leaderboard

Hypothesis: Main/UI thread scheduling or rendering pressure; recording codec and emulator CPU contention are confounders. No root cause proved.

Suggested fix / player benefit: Profile main-thread blocking and rendering during modal dismissal, wallet errors and destination changes. Keep navigation responsive and recover without requiring process restart.

Proof after fixing: Repeat the exact missing-wallet → rapid Connect → Back → Leaderboard sequence 20 times on physical Android and the emulator, both recorded and unrecorded. Capture main-thread traces; require no ANR and timely input response.

P2 · ISS-02

Outfit cards leave an empty third column on the primary test size

Observed: Both grids display two narrow columns with a large empty right strip at 1080×2400/420 dpi. Small profile fits three columns.

Reproduce: Open Hideout at 1080×2400/420 dpi → Scroll Solana and Outfits

Hypothesis: Width formula uses window width while the actual scroll content is narrower, possibly with fractional rounding.

Suggested fix / player benefit: Compute card width from measured container width and gaps so the intended column count fits. This reduces unnecessary scrolling and balances the shop.

Proof after fixing: At both tested densities and an intermediate width, show all columns without overflow, large unused strips or clipped fixed actions.

What changed

A 12.8-second native animation replaces the giant static illustration. A visible tap moves the courier around cover, selects a guard to stop and fire three shots, then collects a phone and reaches the exit. Move, Shoot and Escape can each be replayed. The demo works offline, pauses in the background and while starting a mission, and has static frames for Reduced effects.

The mission-specific tip and collection information remain below the demo. Only Play or Skip starts the mission; watching does not award credits or consume ranked attempts. Back now preserves the selected mission. The real game graphics surface is unmounted while this screen is open.

These screenshots show the static Reduced effects frames. The default screen animates the same sequence.

Safe-area fix

The old Start button shared a fixed-height content stack with large art, text and spacers. The new content always scrolls inside the available space. Start is a separate, non-shrinking footer. A SafeAreaProvider inside the native Modal measures that modal’s system insets, and SafeAreaView protects all four edges.

Implementation references: SafeAreaProvider modal guidance and React Native Modal system-bar behavior.

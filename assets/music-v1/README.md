# Original level soundtrack

Twelve instrumental tracks generated for Steal a Seeker with ElevenLabs Music (`music_v1`).

- `*.mp3`: original API outputs, retained for future mixes.
- `*.m4a`: final 39-second game loops, AAC stereo; only these are bundled by the game.
- `*.json`: prompts, generation identifiers, checksums and processing details.
- `manifest.json`: complete ordered track inventory.

Generate/rebuild with `python3 scripts/generate-level-music.py`. Credentials are read from the shared private ElevenLabs configuration. Existing files are reused. This is original generated music following a cinematic stealth/thriller brief; no Hunter Assassin audio was sampled.

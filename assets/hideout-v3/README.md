# Hideout artwork

Generated on 17 September 2026 via OpenAI Images API, model `gpt-image-2.5-flare`, high quality. User authorized API generation with local credentials. Credentials were not included in prompts or saved in this repository.

The full reference and exact prompts are in `output/imagegen/hideout-v3/`. `classic.webp` is the top scene cropped from the reference. Night/Signal scenes were generated using that scene as an image reference. Runtime WebP assets use quality 90. All prices and player data are rendered by React Native; generated text is not used for live data.

# Boss loading posters

Seven original 2D vertical illustrations generated with OpenAI image generation on 2026-10-05, using the existing approved boss character sheets and courier poster as identity/style references. The private character sheets are not redistributed here.

Each runtime WebP is 900 x 1600. PNG masters are under source/. Exact initial prompts are beside the exports. Generation identifiers are in verification/hunter-stealth/boss-presentation/generation.json.

Toly uses his radio, Mert sounds an alert, Chase vaults cover, Lily aims across a wide field, Vibhu braces behind armour, Akshay fires a burst, and Beeman directs escorts. The middle remains quiet for the real app progress bar. No text or progress is baked into the artwork.

MissionChaseLoader selects by boss id. All later appearances of the same boss reuse that boss poster. Normal missions retain the standard poster. Only the selected image is mounted.

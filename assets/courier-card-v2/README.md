# Courier Card artwork v2

Generated with `gpt-image-2.5-flare` through the OpenAI Image API using the bundled imagegen CLI on 17 September 2026. The existing courier portrait and new leaderboard podium were style references. Prompts and original outputs are under `output/imagegen/courier-card-v2/`.

`background.webp` is a compressed 1024 × 1536 image with no lettering or data. `background.embedded.json` contains the same image as a data URI. Embedding lets SVG-to-PNG export work without external image requests and gives native rendering the same artwork. Only the embedded version is imported at runtime. The source WebP is retained for asset editing and provenance.

`manifest.json` records the source and checksum. The layout study is an intermediate composition reference; its generated sample numerals are not validated game results. It is not used in the app or the public review. All final names, ranks and totals are generated by `src/league/card.ts`.

The API key remains outside the repository. No new token prizes, badges or financial rewards are implied by this illustration.

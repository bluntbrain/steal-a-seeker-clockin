# Weekly League concepts

Three image-generated review concepts, 24 September 2026. These are design references, not live screens or production assets.

- A: Competition board. Personal rank and readable scores first.
- B: Courier podium. Character-driven top-three celebration.
- C: Mission progress. Weekly districts and remaining mission alongside standings.

All sample names, balances, ranks, scores and timers are fictional. No token prizes are shown because the current league code says prizes are not active. The generated images must never replace server-driven UI data.

Generation used the built-in OpenAI image tool, with the approved Hideout concept and existing default courier as references. Exact prompts are under `prompts/`. Keep the existing wordmark, credit chip, palette, bottom navigation and real courier assets when implementing the selected direction. Use one main scroll surface with pinned action/navigation, and provide loading, empty, pass-locked and wallet-disconnected states. No app behavior was changed in this concept task.
